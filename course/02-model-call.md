# 02 · 第一次模型调用

> 本文件是共享课件。Todo、验收、交接与总结均为模板；请在 `course/complete/02-model-call.md` 中记录个人进度，不直接填写本文件。

## 这节要弄懂什么

先把一次请求讲清楚：应用发送什么、模型返回什么、失败在哪一层。使用官方 SDK 完成最小调用，暂不引入 agent 框架。

## 学习与实践 Todo

- [ ] 阅读上节交接，确定项目目录与已有工具链；根据锁文件选择包管理器。
- [ ] 选择一个可用模型服务并查阅官方调用文档；凭证由用户在本地安全配置，agent 不读取或显示密钥。
- [ ] 创建最小 TypeScript 命令行入口，分清应用入口、模型适配层和配置。
- [ ] 发出一次真实请求，说明指令、用户输入与响应的关系。
- [ ] 用结构化输出表达简单结果；对外部响应做运行时校验，区分 TypeScript 类型和实际数据检查。
- [ ] 记录请求耗时、可获取的 token 用量和错误类别，避免记录敏感内容。
- [ ] 演练缺少配置、无效响应、超时和服务失败；只对适合重试的错误做有限重试。

## 理解检查与验收

- [ ] 我能沿着代码指出：输入在哪里进入、请求在哪里发送、结果在哪里处理。
- [ ] 我能解释：模型输出为什么不能直接当作可信的程序参数。
- [ ] 正常请求成功，失败请求有明确错误，不会无休止重试。
- [ ] 已执行适用的类型检查与最小调用验证；记录真实结果。
