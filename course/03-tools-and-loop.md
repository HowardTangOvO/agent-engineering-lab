# 03 · 工具调用与执行循环

> 本文件是共享课件。Todo、验收、交接与总结均为模板；请在 `course/complete/03-tools-and-loop.md` 中记录个人进度，不直接填写本文件。

## 这节要弄懂什么

工具调用是结构化的动作请求，实际执行发生在程序中。把工具结果送回模型，才形成可继续推理的执行循环。

## 学习与实践 Todo

- [ ] 阅读上节代码，用文字描述当前单次调用流程。
- [ ] 定义只读工具：列出指定资料目录、读取其中一个 Markdown 文件。
- [ ] 实现参数校验、目录边界检查与可理解的错误结果；考虑路径穿越和符号链接。
- [ ] 实现请求工具 → 校验 → 执行 → 回传结果 → 继续调用的循环，保持工具请求与结果对应。
- [ ] 从第一版就限制循环步数、工具结果大小和单次操作时长。
- [ ] 明确正常完成、工具失败、预算耗尽和用户取消这几类结束状态。
- [ ] 保存一次可读的执行轨迹：每一步由谁决定、做了什么、得到什么。

## 理解检查与验收

- [ ] 我能逐步解释一条完整轨迹，而不是只看最终回答。
- [ ] 资料内的问题可得到答案；不存在的文件得到可解释结果。
- [ ] 越界路径被程序拒绝，即使模型要求也不能执行。
- [ ] 连续失败或重复调用会在预算内停止。
