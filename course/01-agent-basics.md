# 01 · 理解模型、工具与 Agent

## 这节要弄懂什么

模型负责生成内容或提出动作；应用程序决定是否执行动作、如何提供结果、何时停止。Agent 通常围绕目标反复选择动作并观察结果；普通模型调用和预先确定步骤的工作流也各有适用场景。
