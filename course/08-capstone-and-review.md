## 这节要弄懂什么

把整套能力整合成可运行、可解释、可验证的资料助手。完成标准不是功能数量，而是你能说明它如何工作、为什么这样设计、哪里仍不可靠。

## 综合实践 Todo

- [ ] 阅读全部交接记录，对照实际代码核对功能和剩余阻塞。
- [ ] 整理安装、配置、运行、验证说明；凭证说明只写变量名和安全配置方式。
- [ ] 演示资料检索、来源回答、多轮追问、明确授权保存笔记和新会话恢复。
- [ ] 演示资料不足、工具失败、恶意文档、越界请求和预算耗尽的行为。
- [ ] 完整执行评估和适用的类型检查，修复阻塞；记录命令与实际结果。
- [ ] 删除无用实验代码，保证文档、实际能力和限制一致。
- [ ] 我独立解释一次完整执行轨迹，并提出一个改动，由 agent 实现后验证效果。
