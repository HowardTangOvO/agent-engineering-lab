## 这节要弄懂什么

模型看得到的上下文、应用保存的任务状态、跨会话持久化的记忆是不同的东西。先管理明确的数据，再讨论“让 agent 记住”。

## 理解检查与验收

- [ ] 我能解释：新开一个 agent 为什么需要课程交接记录。
