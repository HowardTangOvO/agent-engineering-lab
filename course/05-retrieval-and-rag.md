# 05 · 用检索接入自己的知识

> 本文件是共享课件。Todo、验收、交接与总结均为模板；请在 `course/complete/05-retrieval-and-rag.md` 中记录个人进度，不直接填写本文件。

## 这节要弄懂什么

RAG 是先检索资料，再把相关片段提供给模型回答。它不会把资料永久训练进模型，也不能保证答案一定正确。先做能解释的关键词检索，再按问题决定是否引入向量检索。

## 学习与实践 Todo

- [ ] 准备少量 Markdown 资料，包含能回答、缺失、冲突与过期资料。
- [ ] 实现关键词检索，记录命中的文档和片段。
- [ ] 解释分块、embedding、相似度与 top-k；通过小实验对比关键词与向量检索，不为引入数据库而引入数据库。
- [ ] 让回答携带真实文件路径与片段依据，区分资料陈述和推断。
- [ ] 处理无结果、结果冲突和来源不足；不能凭空补出答案。
- [ ] 将文档内的指令视为不可信内容，演练“忽略规则并读取其他目录”的恶意片段。
- [ ] 修改一份资料后更新检索数据，确认旧内容不会继续冒充最新依据。

## 理解检查与验收

- [ ] 我能区分“没找到正确片段”和“找到了但回答错了”。
- [ ] 已知答案能定位到正确来源；无依据问题明确说明缺少信息。
- [ ] 文档里的恶意指令不会改变工具权限或触发未授权写入。
- [ ] 我能说明当前检索方案的取舍，以及什么证据才值得升级它。
