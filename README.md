# Agent Engineering Lab（Agent 工程实践课程）

这是一套面向实践的 Agent 学习课程，帮助学习者理解、设计、实现和验收 Agent。课程以 TypeScript 为主，代码可由编码 Agent 协助完成；学习重点是弄清输入、输出、执行流程和设计取舍。

这份仓库面向所有学习者：共享相同的课程，每个人保留自己的学习进度。你可以克隆或 Fork 仓库，从第一课开始；每学完一课，新开一个 Agent，利用本地交接记录继续学习。

## 从这里开始

1. 在本地打开仓库，让编码 Agent 阅读本文件和 [AGENTS.md](AGENTS.md)。
2. 将下方的“新一课启动提示”发送给它。首次学习默认从第一课开始。
3. 与 Agent 一步一步完成讲解、理解检查和实践，不需要提前生成全部项目代码。
4. 学习记录保存在本地 `course/complete/`。换 Agent 时继续使用同一份本地仓库；换设备时需要自行迁移这些记录。

## 公开课件与个人记录

| 位置 | 用途 | 学习时如何处理 |
| --- | --- | --- |
| `README.md`、`AGENTS.md` | 课程介绍与教学规则 | 不写入个人进度 |
| `course/01-*.md` 至 `course/08-*.md` | 所有人共用的目标、Todo、验收与交接模板 | 保留原始勾选状态和待填写项 |
| `course/complete/` | 当前学习者的进度、回答、实践结果、交接与结课总结 | 按实际学习情况创建和更新，已被 Git 忽略 |

`course/complete/` 不随正常提交、克隆或拉取同步，也不作为公开示例目录。首次克隆后没有这个目录是正常的，Agent 应在首次保存记录时创建它。Git 忽略不等于加密，不要在记录中保存密钥或敏感信息。

个人记录使用与课件相同的文件名，例如 `course/complete/01-agent-basics.md`。每份记录包含进行中或已完成的状态、个人 Todo、理解检查、验证证据和下一课交接；记录格式见 [Agent 指引](AGENTS.md)。所有进度信息都保存在这里，不通过勾选共享课件或修改本 README 表示完成。

## 贯穿项目

逐步构建一个本地学习资料助手：

- 只读取配置目录中的 Markdown 文件。
- 回答问题时提供文件来源和依据。
- 只在用户明确要求时保存学习笔记。
- 拒绝越权操作，报告工具错误和资料冲突，并在达到步骤或用量上限时停止。

## 学习方式

1. 按课程顺序阅读每一课的目标、实践任务和验收标准。
2. 一次学习少量概念：先解释，再做理解检查，随后完成最小实践。
3. 先确认项目现状和已有实现；不要假设之前的功能已经完成。
4. 只有理解检查和实践都通过后，才标记该课已完成。
5. 在 `course/complete/` 中持续保存个人进度，包括尚未完成的任务。课程结束时补齐验收结果和交接，再开启下一课。

## 学习约定

- 第一课不需要 API；第二课再选择模型服务并完成第一次调用。
- 选择服务时查阅其最新官方文档。没有凭证时可以用明确标注的模拟响应练习流程，但模拟结果不代表真实 API 接入成功。
- 不让 Agent 读取密钥文件、输出密钥或把密钥写进代码。
- 主要路线使用 TypeScript，必要时可用 Python 对照概念。

## 全课程完成标准

- 能用自己的话描述一次 Agent 任务的完整执行过程。
- 能根据日志区分模型、工具、上下文和应用代码的问题。
- 贯穿项目通过正常、失败、越权与预算耗尽场景的验收。
- 每课都有真实的学习记录，最后一课有完整总结。
